# TG Analytics

Внутренний инструмент операционной аналитики рабочих чатов Telegram.
По выгрузке чата из Telegram Desktop показывает нагрузку команды, скорость ответов, активность вне рабочего времени и вклад каждого участника.

Данные обрабатываются локально в браузере: файл никуда не загружается, бэкенда нет.

## Возможности

**Сводка и KPI**
- объём сообщений и среднее в день, число участников, доля активных дней
- медианное время ответа коллегам
- доля сообщений вне рабочего времени (пн–пт, 9:00–19:00)
- доля ответов в тредах и репостов
- автоматическая текстовая сводка: пик нагрузки, самый медленный ответ, переработки

**Команда**
- таблица по участникам: сообщения и доля, медиана ответа, работа вне рабочего времени, полученные реакции, последняя активность
- сортировка по любому столбцу
- подсветка рисков: ответ дольше часа, больше 25% сообщений вне рабочего времени
- экспорт таблицы в CSV (открывается в Excel без перекодировки)

**Нагрузка**
- динамика активности по дням или неделям
- тепловая карта «день недели × час»
- распределение по дням недели

**Контент**
- ключевые темы (частотные слова без стоп-слов) и хэштеги
- типы сообщений, реакции, сообщения с наибольшим откликом

**Периоды:** 7 дней, 30 дней, квартал, год, всё время. Период отсчитывается от последнего сообщения в выгрузке.

## Как пользоваться

1. Telegram Desktop → нужный чат или группа → ⋮ → **Экспорт истории чата**
2. Снять галочки с медиафайлов, формат: **Машиночитаемый JSON**
3. Открыть TG Analytics и загрузить `result.json`

Для знакомства с интерфейсом есть кнопка «Открыть демо», которая загружает сгенерированный чат проектной команды.

> Нужен экспорт одного чата. Полный экспорт аккаунта (Настройки → Продвинутые → Экспорт данных) не поддерживается.

## Как считаются метрики

| Метрика | Методика |
|---|---|
| Время ответа | Разница между сообщением и reply на него от другого участника. Учитываются ответы в пределах 3 суток. Используется медиана, а не среднее, чтобы единичные ответы через сутки не искажали картину |
| Вне рабочего времени | Сообщения в выходные, а также до 9:00 и после 19:00 в будни. Время берётся локальное, по часовому поясу браузера |
| Активные дни | Дни, в которые было хотя бы одно сообщение |
| Ключевые темы | Слова от 3 символов без стоп-слов, ссылок и чисел |

Ограничение: ответы без reply (просто следующее сообщение в чате) в расчёт времени ответа не попадают.

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # локальный просмотр сборки
npm run lint     # oxlint
```

Стек: React 19, TypeScript, Vite, Chart.js (react-chartjs-2).

Сборка статическая: содержимое `dist/` можно разместить на любом статическом хостинге или во внутренней сети.

### Структура

```
src/
  types.ts              типы выгрузки Telegram и внутренней модели
  lib/
    parser.ts           result.json → Chat
    stats.ts            расчёт метрик, рабочее время, время ответа, фильтр периода
    dates.ts            работа с датами (локальное время, неделя с понедельника)
    format.ts           форматирование чисел и длительностей, экспорт CSV
    demo.ts             генератор демо-данных (детерминированный)
  components/
    Dropzone.tsx        экран загрузки
    Dashboard.tsx       дашборд и сводка
    TeamTable.tsx       таблица команды
    Charts.tsx          графики
    Heatmap.tsx         тепловая карта нагрузки
    Lists.tsx           темы, реакции, топ сообщений
  chartSetup.ts         регистрация Chart.js и палитра
```

Рабочие часы и пороги подсветки задаются константами в `src/lib/stats.ts` (`WORK_START`, `WORK_END`) и `src/components/TeamTable.tsx` (`SLOW_REPLY_MINUTES`, `HIGH_AFTER_HOURS`).
